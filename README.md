# Probleme_Resolu

Ce depot sert a centraliser les problemes que je rencontre, a expliquer comment je les ai resolus, et a garder une trace claire des solutions utiles dans le temps.

## But du depot

- noter chaque probleme rencontre
- decrire la solution appliquee
- conserver un historique des corrections et ameliorations
- partager facilement ces resolutions sur GitHub

## Contenu actuel

- `Exemple de Feuille de calcul.xlsx`
- `Mon Feuille de Calcul.xlsx`

## Comment ce depot sera utilise

Quand je rencontre un probleme, je l'ajouterai ici avec :

- une description du probleme
- le contexte dans lequel il est apparu
- les etapes pour le resoudre
- le resultat final ou la bonne pratique retenue

## Evolution

Ce depot sera ameliore progressivement a chaque nouveau probleme resolu afin de devenir une reference simple, pratique et publique.
